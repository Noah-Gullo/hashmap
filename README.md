## HashMaps
# Description:
An exploration of HashMaps through JavaScript including their common operations such as getting keys, values, rehashing, and many more. It did build upon the [Linked Lists] (https://github.com/Noah-Gullo/linked-lists) that I created earlier.

# Reflection:
Practicing Test Driven Development (TDD) was difficult, but really gave me the confidence that my functions were complete and done once all the tests passed. This was definitely more complicated than my LinkedLists project, but I feel like I understand HashMaps far more now than I did before. It was also very satisfying building out the functionality.
